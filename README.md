# Casa Vestigio

Pequeño proyecto de práctica para aprender el flujo de trabajo con Git y GitHub.

Contiene un módulo de utilidades de saludos en español.

## Uso

```python
from saludos import saludar, despedir

print(saludar("Eduard"))   # ¡Hola, Eduard!
print(despedir("Eduard"))  # ¡Hasta pronto, Eduard!
```

## Ejecutar las pruebas

```bash
python -m pytest
```
